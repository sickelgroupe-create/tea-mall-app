## 仍需在微信开发者工具完成

1. 关闭或移开另一个小程序项目，确保当前窗口标题为“分销茶叶商城”。
2. 导入 `dist/build/mp-weixin`，或使用已修复的 `unpackage/dist/dev/mp-weixin`。
3. 执行“清除全部缓存”并重新编译。
4. 保存游客登录页、失效 Token 清理、正常登录后三组 Console/Network 截图。
5. 确认三张图可见、无大面积空白、Console 红色错误为 0、Network 无图片 404 和重复认证失败。
6. 对照原始设计稿确认字体、尺寸、间距和布局。
