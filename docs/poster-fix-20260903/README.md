## 根因和修复

旧代码按 448×595 像素绘图，但画布使用随屏宽变化的 750rpx×996.1rpx；二维码仍采用固定坐标，窄屏保存时超出实际画布。导出也未指定裁剪和目标尺寸。

- H5 与小程序固定输出 896×1190 PNG，画布样式通过同一套像素常量生成，避免页面 rpx 批量转换再次修改离屏画布。
- 将离屏画布移到 scroll-view 外，不参与滚动内容布局。
- 明确导出起点、宽高和目标尺寸，绘制前检查实际画布尺寸。
- 两端共用二维码绘制函数，白底距海报右边 56px、底边 72px，四周至少保留四个模块的空白。
- 使用整数像素绘制二维码模块，避免原代码 ceil 导致相邻模块相互覆盖。
- 导出失败、二维码数据异常和画布尺寸不匹配时返回错误，不静默保存裁切图。
