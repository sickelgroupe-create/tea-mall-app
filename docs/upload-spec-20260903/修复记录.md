## 根因

1. 售后凭证与留言板共用 POST `/mall/community/images`。原 Java 代码调用 `AjaxResult.success(FileUploadUtils.upload(...))`，上传函数返回 String，因此选中 `success(String msg)` 重载，图片路径进入 `msg`，没有 `data`。前端公共上传解析器只读取 `data` 或约定的地址字段，正好触发截图中的“上传成功但服务端未返回图片地址”。代码和回归测试支持这个原因，不据此声称核验过用户原图片是否已在生产存储，也不判断服务器卡死。
2. 商品名称已含 `100g`，售后申请/详情又追加 SKU 的 `spec=100g`，导致重复。只在展示层去重，不改商品、SKU、订单名称或数据库。
